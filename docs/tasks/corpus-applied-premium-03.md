# CORPUS-APPLIED-03 — Beautiful applied systems, research only

Owner: Claude Opus 5.5; Codex reviews. Read AGENTS.md,
docs/agent-coordination.md, docs/color-corpus-integration-assessment.md,
docs/research/corpus-source-audit-01.md and
docs/research/corpus-applied-projects-02.md first.

Find 3–5 visually excellent, real projects where a deliberate palette has
been applied convincingly to a finished product, packaging system, interior,
identity or digital interface. Favor the premium craft/design level the user
wants for Inspiration, not merely a well-documented civic palette. Prefer
primary maker/brand/design-studio case studies and specific real-world
application images. For each candidate, give direct evidence links, exact
documented colors if published, image/reuse rights or unresolved restrictions,
what ColorVerse may safely show or link, and what remains unknown. Separate
documented source colors from any prospective ColorVerse interpretation.

Rank candidates by both visual fit and readiness. Do not generate or infer
hex values from photography, invent 5-color records, download/ingest source
assets, scrape palette platforms, or assert rights without evidence. Be clear
if no candidate is import-ready. Output one concise decision-ready report at
`docs/research/corpus-applied-premium-03.md`; no product/code changes. Run
link/source checks where possible, git diff --check, commit locally if
permitted, report exact revision. No push/deploy.
